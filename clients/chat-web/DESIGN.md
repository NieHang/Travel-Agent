# Hilda 前端设计规范

`clients/chat-web` 的设计语言：视觉、组件、动效和文案。新增或修改界面前先读本文件。规则写成数值和禁令，是为了能逐条检查；没有写到的情况，按第 1 节的原则判断。

token 定义在 [app/globals.css](app/globals.css)，动效参数在 [lib/motion.ts](lib/motion.ts)。本文件与代码不一致时，先改到一致再继续。

## 1. 原则

1. **底面安静，内容说话。** 界面本身只用暖中性色。色彩来自照片和少量 tint 色块，不来自装饰。
2. **能看懂就不写字。** 信息用"图标 + 短数值"、照片、位置和分组来表达。需要一句话解释的布局，先改布局。
3. **主操作只有一种样子。** 每个视图最多一个主操作，永远是墨色实心的圆形或胶囊按钮。
4. **动效表达连续性，不做装饰。** 一个元素换了状态或位置，就让它变过去或走过去。没有状态变化的地方不动。

## 2. 色彩

所有界面（包括落地页和登录页）使用同一套暖色体系。token 目前带 `trip-` 前缀，但它们是全局的。

### 2.1 中性色

| 用途 | token | 值 |
|---|---|---|
| 页面底色 | `trip-ground` | `#faf6f3` |
| 面板、抽屉、底部弹层 | `trip-panel` | `#fff8f7` |
| 卡片表面 | `white` | `#ffffff` |
| 控件的静止填充（未选中的标签、头像底、输入气泡） | `trip-fill` | `#efe8e4` |
| 图片占位、选中或强调的浅底 | `trip-tile` | `#f9eae8` |
| 分隔与描边 | `trip-line` | `#e6ddd8` |
| 主文字、图标、主操作填充 | `trip-ink` | `#1f1d1e` |
| 次要文字（日期、数量、地点） | `trip-muted` | `#6b6566` |
| 遮罩 | `trip-scrim` | `rgb(24 14 8 / 0.62)` |

文字只有 `trip-ink` 和 `trip-muted` 两级，再加深色底上的白色。不用透明度造第三种灰。

### 2.2 强调色与语义色

| 用途 | token | 值 |
|---|---|---|
| 品牌标识 | `trip-brand` | `#e5532d` |
| 当前项、关键标记（当前这一天、地图上选中的点） | `trip-accent` | `#c8442b` |
| 进行中、已完成 | `trip-success` | `#4fa83a` |
| 错误、危险操作 | `danger` | `#e5484d` |

### 2.3 tint 色对

用于给同类项目分色（清单分类、合集）。每对是一个浅底加一个同色相的深色，只能成对使用：`tint-*` 做背景，`tone-*` 做其上的图标和文字。

`rose` · `violet` · `sky` · `apricot` · `olive`

### 2.4 规则

- 一屏之内，`trip-accent` 和 `trip-brand` 合计不超过两处。主操作用 `trip-ink`，不用强调色。
- tint 色对只用于分类，不用于表示状态或强调。
- 禁止渐变（照片上压字用的遮罩除外）、纯黑 `#000`、高饱和色块。
- 禁止在组件里写十六进制色值。需要新颜色时，先在 `globals.css` 加 token，并在本节登记用途。
- `ink`（`#1b1535`）、`lime`、`paper`、`stage-*` 是旧的落地页配色，正在淘汰。新代码不得使用。

## 3. 字体与字号

### 3.1 字体

- 全局：`font-trip`（Outfit + Noto Sans SC）。
- 强调字体：衬线斜体，只用于落地页和空状态的大标题里的**一个**词或短语，并配 `trip-accent` 或一个 `tone-*` 色。中文没有斜体，中文界面里这个词只换颜色，不合成倾斜。
- Plus Jakarta Sans（`font-sans`）随旧配色一起淘汰。

### 3.2 字阶

只用下面七档。行高和字重按表取，不另外组合。

| 档位 | 字号 | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| hero | 44px | 700 | 1.05 | 落地页主标题 |
| display | 32px | 700 | 1.1 | 页面标题、封面标题 |
| heading | 24px | 700 | 1.2 | 卡片主标题、关键数值 |
| title | 18px | 600 | 1.3 | 分组标题、列表项标题 |
| body | 15px | 400 | 1.5 | 正文、对话内容 |
| label | 13px | 500 | 1.4 | 按钮、标签、元信息 |
| caption | 12px | 400 | 1.3 | 时间戳、图注 |

- 层级靠字号和字重拉开，相邻两级至少差一档字号或一级字重。不靠颜色以外的装饰（下划线、斜体、全大写）。
- 标题字距：英文 `-0.04em`，中文 `-0.02em`（已在 `globals.css` 的 `h1`–`h3` 上）。
- 数值与单位写在一起时，数值用 `trip-ink`，单位或标签用 `trip-muted`，同一字号。
- 不使用 `font-extrabold` 和 14px、16px、17px、20px。

## 4. 间距、圆角与阴影

### 4.1 间距

所有间距取 4 的倍数：`4 · 8 · 12 · 16 · 20 · 24 · 32 · 48 · 64`。

| 关系 | 取值 |
|---|---|
| 图标与它的文字 | 4 或 8 |
| 同组内的元素 | 8 或 12 |
| 卡片内边距 | 16 或 20，四边相等 |
| 同级卡片之间 | 12 或 16 |
| 分组之间 | 24 或 32 |
| 页面区块之间 | 48 或 64 |

组内间距必须小于组间间距。拿不准时取大的一档，宁可留空。

### 4.2 圆角

| token | 值 | 用途 |
|---|---|---|
| `rounded-trip-panel` | 36px | 页面级面板 |
| `rounded-trip-lg` | 28px | 大幅图片卡片、地图 |
| `rounded-trip-md` | 22px | 标准卡片、菜单 |
| `rounded-trip-sm` | 20px | 气泡、列表块、标签容器 |
| `rounded-trip-xs` | 16px | 卡片内的图片、小卡片、列表行 |
| `rounded-trip-tail` | 6px | 对话气泡靠近发送方的那一角 |
| `rounded-full` | — | 按钮、标签、头像、图标按钮 |

- 嵌套时保持同心：内圆角 = 外圆角 − 内边距，例如 `rounded-[calc(var(--radius-trip-md)-12px)]`。算出来小于 8px 时取 8px。
- 禁止任意值圆角（如 `rounded-[30px]`）。`rounded-card`、`rounded-panel` 是旧 token，不再使用。

### 4.3 阴影

| token | 用途 |
|---|---|
| `shadow-trip-panel` | 页面级面板，一屏一个 |
| `shadow-trip-card` | 浮在底面上的卡片 |
| `shadow-trip-pin` | 小的浮起元素（图钉、勾选标记） |
| `shadow-trip-label` | 压在图片或地图上的标签 |

- 一个表面用阴影**或**描边来和底面分开，不同时用。
- 禁止卡片套卡片。卡片内部的分组用间距，不够时用 `trip-fill` 或 `trip-tile` 的浅底，不再加阴影和描边。
- 禁止用分割线分隔已经有间距分开的内容。分割线只用于长列表的行与行之间。

## 5. 图标

- 使用 `lucide-react`，保持默认线宽。不混用其他图标库，不用 emoji 充当图标。
- 尺寸三档：16（与 label、caption 同行）、20（默认）、24（导航、空状态）。
- 可点击的图标按钮，命中区域不小于 44×44（`size-11`），形状为圆形。
- 图标与文字同行时颜色相同。
- 只有图标的按钮必须有 `aria-label`。

## 6. 组件

先查 HeroUI 和 [components/ui](components/ui)，有就用，不重写。

### 6.1 操作

| 场景 | 用 | 样式 |
|---|---|---|
| 主操作（每个视图最多一个） | `PillButton` | `trip-ink` 实心，白字 |
| 次要操作 | `PillButton` | `trip-fill` 填充，或白底配 `trip-line` 描边 |
| 只有图标的操作 | 圆形图标按钮 | 白底或 `trip-fill`，44×44 |
| 危险操作 | `ConfirmDialog` 里的确认按钮 | `danger` |
| 文字链接 | 仅用于导航到其他页面 | `trip-ink` 加下划线 |

- 行内的次要操作（编辑、删除、更多）平时隐藏，在该行悬停、聚焦或被触摸时显示。触发范围只限这一行，浮层锚定在触发它的元素上。
- 触摸设备没有悬停：次要操作收进"更多"按钮，按钮始终可见。

### 6.2 选择与筛选

| 场景 | 用 |
|---|---|
| 在 2–5 个互斥视图间切换 | `PillTabs` |
| 多选筛选、展示属性 | `Chip` |
| 从一组选项里选一个并提交 | `choice` 组件（`components/ai-ui`） |
| 开关一个设置 | HeroUI `Switch` |

### 6.3 内容

- **卡片**：一张卡片表达一个对象（一次行程、一家酒店、一天）。有照片时照片在上、占满宽度，信息在下。
- **元信息行**：`图标 + 数值 + 单位`，13px，多项之间间距 16。一行最多三项。
- **状态**：用 `Chip` 加一个 8px 的色点，不用整块色底。
- **空状态**：虚线描边的容器，一个图标、一个 title 档的标题、一个操作。
- **加载**：内容区用 `Skeleton`，形状与将要出现的内容一致；整页等待用 `BrandLoader`。
- **反馈**：操作结果用 `toast`；需要用户决定的用 `ConfirmDialog`。

### 6.4 禁令

- 不为同一种语义造第二个组件。发现重复时合并，而不是新增变体。
- 不用 `Chip` 当按钮，不用按钮当标签。
- 不在标题下加副标题或说明句。

## 7. 动效

### 7.1 参数

弹簧只从 `lib/motion.ts` 的 `springs` 取，组件里不写 `stiffness`、`damping`。

| 名称 | 手感 | 用途 |
|---|---|---|
| `snappy` | 快，轻微回弹，约 250ms | 按压反馈、小图标的状态变化 |
| `smooth` | 快，几乎不回弹，约 250ms | 选中指示器、列表重排、容器尺寸变化 |
| `drawer` | 不回弹，约 250ms | 抽屉、底部弹层 |
| `gentle` | 慢，约 450ms | 内容入场 |

透明度和颜色不用弹簧：用 150ms 的 `easeOut`；进度类的描边动画用 280ms 的 `easeOut`。

### 7.2 模式

每种状态变化只有一种做法。

| 变化 | 做法 |
|---|---|
| 选中项改变（标签、分段） | 指示器用共享 `layoutId` 滑到新位置，`springs.smooth`。文字颜色同时用 150ms 过渡。 |
| 按压 | `whileTap` 缩到 0.96，悬停放到 1.03，`springs.snappy`。只用于按钮和 `Chip`。 |
| 图标换状态（播放/暂停、展开/收起、完成） | 同一个 SVG 内形变或旋转，不整体替换。做不到形变时，旧图标缩到 0.6 淡出、新图标从 0.6 弹入，`springs.snappy`。 |
| 文字换内容（排序标签、状态文案、数值） | `AnimatePresence mode="wait"`：旧文字上移 8px 淡出，新文字从下方 8px 淡入，各 150ms。 |
| 内容入场 | `enter(index, reduced)`：上移 12px 加淡入，每项错开 40ms，最多错开 8 项。 |
| 列表增删、重排 | `layout` 加 `springs.smooth`；删除项高度和透明度归零。 |
| 抽屉、底部弹层 | 从所在边滑入，`springs.drawer`；遮罩 150ms 淡入。 |
| 展开/收起 | 高度用 `springs.smooth`，内容在高度变化的后半段淡入。 |
| 校验失败 | 水平抖动一次（`AuthPanel` 的做法），不变红闪烁。 |
| 等待模型回复 | `trace-shimmer`。 |

### 7.3 规则

- 只动 `transform` 和 `opacity`。尺寸变化交给 `layout`，不直接动 `width`、`height`、`top`、`left`。
- 回弹只给小元素（按钮、标签、图标）。面板、卡片、抽屉、列表不回弹，不旋转。
- 退出比进入快：退出不超过 150ms，不做位移以外的效果。
- 由用户操作直接触发的反馈在 100ms 内开始。入场以外的动效不加延迟。
- 循环动画只用于加载和等待。落地页的漂浮卡片是唯一例外。
- 每个动效都读 `useReducedMotion()`。为真时：位移、缩放、形变全部去掉，只保留透明度变化；`layoutId` 指示器用 `{ duration: 0 }`；循环动画停止。
- 不用 Tailwind 的 `transition-*` 做位移和缩放；它只用于颜色和透明度。

## 8. 文案

- 一个视图只有一个标题。分组标题用名词，不超过四个词（中文不超过八个字）。
- 不写口号、副标题和解释布局的句子。必须保留的说明收进 tooltip 或提示条。
- 按钮用动词开头，说明结果："开始规划"，而不是"确定"。
- 数值优先于句子："38 张照片"写成图标加"38"。
- 语气是书面的陈述，不用感叹号，不用营销或口语化的说法。
- 所有文案进 `messages/{en,zh}.json`，两种语言的 key 一致。

## 9. 验收

改动界面后，在浏览器里看真实渲染，不以代码里的数值为准。提交前逐项确认：

- [ ] 桌面宽度和 375px 宽度下都没有溢出、遮挡和意外换行。
- [ ] 中文和英文两种语言下，长文案没有撑破容器。
- [ ] 间距都是 4 的倍数，圆角、颜色、阴影、字号都来自本文件的表。
- [ ] 没有卡片套卡片，没有阴影加描边，没有多余的分割线和说明文字。
- [ ] 视图里只有一个墨色主操作。
- [ ] 键盘可以到达每个可操作元素，焦点环可见。
- [ ] 打开系统的"减少动态效果"后，界面仍然可用且没有位移动画。
- [ ] 动效用的是 7.2 里对应的模式，参数来自 `lib/motion.ts`。

## 10. 尚未落地

以下是本规范与当前代码的差距。在对应的迁移完成前，新代码按本规范写，旧代码不必为了对齐而改动。

| 项目 | 现状 | 目标 |
|---|---|---|
| 落地页、登录页配色 | 使用 `ink` / `lime` / `stage-*` 和 Plus Jakarta Sans（约 16 个文件） | 迁到暖色体系和 `font-trip`，然后删除旧 token 和字体 |
| token 命名 | 全局 token 带 `trip-` 前缀 | 去掉前缀，一次性重命名 |
| 字阶 | 用 `text-[13px]`、`text-[15px]` 等任意值，另有 14、16、17、20px | 在 `@theme` 里定义七档字阶 token 并替换 |
| 衬线强调字体 | 未加载 | 选定并加载一款衬线斜体，仅拉丁字符 |
| 旧圆角与阴影 | `rounded-card`、`rounded-panel`、`shadow-float`、一处 `rounded-[30px]` | 换成 4.2、4.3 的 token 后删除 |
| 零散的动效时长 | `ReplyTrace`（0.28s）、`BrandLoader`（1.2s）、`FloatingCard`（6s）写在组件里 | 在 `lib/motion.ts` 里补上时长常量并引用 |
| 文字滚动替换、图标形变 | 没有共用实现 | 第二次用到时抽成 `components/ui` 里的组件 |
