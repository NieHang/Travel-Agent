## 实测发现及修复

初次测试当前源码时，真实模型接口拒绝了 SDK 生成的 JSON Schema 属性路径引用，导致 HTTP 502。增加回归断言后复现，改为从原 Zod schema 生成并展开本地引用，再通过原有完整校验检查模型结果。修复后上述 12 项通过。

原有 4001 端口服务接收带 locale 的请求时返回 HTTP 400，因此本次成功结果来自当前源码的临时服务。原服务需重启加载当前代码后再使用。

完整请求、响应、状态码及耗时见 [JSON 报告](2026-10-04-ui-protocol-live-test.json)。初始 4001 服务结果见 [初始运行报告](2026-10-04-ui-protocol-live-old-runtime.json)。报告不包含访问令牌或 API 密钥。
